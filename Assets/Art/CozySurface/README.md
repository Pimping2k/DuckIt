# Обновление интеграции

Для пыли, грязи, старой краски и ржавчины теперь используется основной Restoration/ToonRestorable. Полная актуальная инструкция — [IntegratedRestoration.md](IntegratedRestoration.md). CozySurface остаётся вариантом статического предпросмотра. Новые компоненты не нужны.

# CozySurface: материалы и настройка

Новые файлы: четыре `.mat`, один `.shader`, два `.hlsl` и служебные `.meta`. Новых C#-скриптов, компонентов или установщика нет. Существующие сцены, материалы и игровые скрипты не заменяются.

## Что назначать

| Материал | Назначение |
|---|---|
| M_Cozy_Base | Базовый чистый материал. Белый цвет не перекрашивает назначенную текстуру. |
| M_Cozy_Mint | Готовая мятная краска для объектов без текстуры. |
| M_Cozy_DirtyPreview | Та же мятная поверхность под грязью. Dirt Amount меняет количество грязи прямо в Inspector. Это предпросмотр без инструмента. |
| M_Cozy_Restorable | Для существующего RestorableItem. Включено чтение его масок очистки. |

## Обычный предмет

1. В Project найди `Assets/CozySurface/Materials`.
2. Дублируй нужный материал через Ctrl+D, чтобы настраивать конкретный предмет отдельно.
3. Перетащи его на объект в Scene или в слот Mesh Renderer → Materials. При нескольких слотах назначь нужный слот отдельно.
4. В Clean Texture положи исходную цветовую текстуру предмета. Clean Color оставь белым, если хочешь сохранить её цвета. Без текстуры Clean Color задаёт основной цвет.

Новый материал не может сам забрать индивидуальные текстуры всех объектов. Если предмет уже использует URP/Lit, можно дублировать его старый материал и выбрать Shader → Restoration → CozySurface: одинаковые свойства BaseMap/BaseColor обычно сохраняются. Затем вручную поставь настройки из таблицы ниже. Для старых Standard-материалов текстуру MainTex нужно перенести в Clean Texture самостоятельно.

## Очищаемый предмет

1. Вне Play Mode назначь копию M_Cozy_Restorable в Renderer.
2. Перенеси исходную текстуру в Clean Texture. На компоненте RestorableItem выбери шейдер `ToonRestorable` в поле Toon Shader. Иначе Awake этого компонента создаст старый ToonRestorable.
3. Сохрани сцену или prefab и запусти игру.
4. Для равномерного покрытия включи существующий Uniform Dust на RestorableItem. В WearPreset включай необходимые слои Dust, Dirt, Old Paint и Rust. Интегрированный ToonRestorable отображает все четыре канала, и прогресс учитывает те же маски.
5. Компонент сам назначает UV и динамическую маску. Для инструментов нужна развёртка без перекрытий.

Use Cleaning Masks включён — грязь задают каналы R/G маски и инструмент. Dirt Amount в этом режиме не используется. Use Cleaning Masks выключен — Dirt Amount задаёт грязь статически, без компонента.

Цвет и плотность грязи настраиваются через Opaque Dirt Color / Dirt Opacity / Color Hidden By Dirt в материале. Старые Dust Pixels / Dust Ragged / Clean Glow / Dust Color / Dust Opacity на RestorableItem не управляют новым визуалом: имена свойств оставлены скрытыми только для совместимости существующего кода.

## Основные настройки

| Параметр | Что меняет | Начальное значение |
|---|---|---|
| Clean Texture | Цвет и рисунок чистой поверхности | Собственная текстура |
| Clean Color | Умножает цвет текстуры; без текстуры задаёт цвет | Белый / мятный |
| Soft Highlight Strength | Сила обычного мягкого блика | 0.22; дерево 0.05–0.12, керамика 0.25–0.40 |
| Shadow Strength | Насколько тень темнее освещённой стороны | 0.60 |
| Shadow Tint | Оттенок тени | Приглушённый серо-лиловый |
| Light Transition Position | Положение перехода света в тень на форме | 0.36 |
| Light Transition Softness | Плавность этого перехода | 0.28; больше — мягче |
| Light Color Contribution | Влияние цвета и интенсивности основного света | 0.50 |
| Rim Strength | Лёгкая подсветка краёв | 0.015; лучше 0–0.05 |
| Dirt Amount | Статическая грязь при выключенных масках | 0 чисто; 1 грязно |
| Opaque Dirt Color | Цвет плотной грязи | RGB 0.27 / 0.25 / 0.21 |
| Dirt Opacity | Насколько грязь закрывает исходную текстуру | 0.88 |
| Color Hidden By Dirt | Потеря насыщенности под грязью | 0.75 |

Light Transition Softness не меняет мягкость падающей тени. Последняя задаётся источником света и URP Asset.

## Свет и камера

В текущем PC_RPAsset уже включены HDR и Soft Shadows; MSAA сейчас выключен. Для стартовой проверки: один тёплый Directional Light с интенсивностью около 1–1.3, мягкие тени, достаточное окружение без полностью чёрной теневой стороны. Смотри результат через игровую камеру. При необходимости включи MSAA 4x в PC_RPAsset либо используй сглаживание камеры, подходящее выбранному рендереру.

В существующем Global Volume попробуй Tonemapping ACES, Post Exposure 0…+0.35 и умеренный Bloom около 0.1–0.2. Включи Post Processing у игровой камеры. Это отправные значения, а не обязательные настройки. Не добавляй второй глобальный Volume поверх уже настроенного без необходимости. В проекте эти параметры автоматически не менялись.

Этот материал не создаёт текстуры, скругления моделей, освещение или готовую сцену Hozy. Он даёт единый мягкий материал и плавный слой грязи, который открывает исходную текстуру. Это собственный простой шейдер без PBR.

## Проверено

Unity 6000.0.60f1 / URP 17 / Forward+: импорт и сохранение четырёх настоящих .mat, ссылки на шейдер после повторного импорта, используемые проходы шейдера и рендер. На копии текущего RestorableItem проверено: выбранный шейдер и параметры материала сохраняются при Awake; существующий Stroke очищает R маски с 1 до 0. Полностью очищенная поверхность совпадает с вариантом без маски. Полный сценарий инструментов и прогресса в основной игровой сцене не запускался.

Ограничения: непрозрачные поверхности, нет PBR, Meta/lightmaps и DepthNormals. Для полноценного baked GI или SSAO, зависящего от DepthNormals, потребуется расширение шейдера.
