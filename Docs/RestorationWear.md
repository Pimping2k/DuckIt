# Износ и визуальный стиль

Полосы на вазе находятся в `Assets/Art/Textures/Vase/Vase_Test_Albedo.png`.
Это орнамент основы, который останется после очистки. Раньше prefab вазы использовал
`Wear_Dusty`: только пыль с coverage = 1, без старого покрытия.

## Новое поведение

- `Chipped` формирует потери покрытия у верхней кромки, основания и в нескольких
  связных зонах повреждения. Seed меняет зоны и неровность границ; расположение
  больше не определяется случайным выбором ячеек. `Flakes` остаётся ячеистым паттерном.
- `noiseScale`: больше значение — мельче участки. `sharpness` управляет чёткостью края,
  `breakup` — его неровностью. Генерация идёт в координатах меша, независимо от UV-швов.
- В пресете `coverageVariation`, `scaleVariation`, `toneVariation` задают допустимые
  отклонения параметров каждого экземпляра. Сам ScriptableObject не изменяется.
- `wearSeed = 0` создаёт новый seed в Awake. Ненулевое значение воспроизводит начальное
  состояние при том же меше, пресете, разрешении маски и ориентации объекта.
  Для загрузки задайте seed до активации объекта. Seed восстанавливает начальный износ;
  для сохранения выполненной реставрации дополнительно нужны текущие wear/paint-маски.
- Prefab `Vase - Restorable` использует `Wear_CeramicChipped`, без ржавчины.
  `texturedCoating` помещает исходный орнамент на оставшуюся глазурь, сколы показывают
  матовый `substrateColor`. Для однотонной старой краски отключите texturedCoating:
  тогда её цвет снова задаёт oldPaint.color. Параметр действует только с включённым oldPaint.
- `TopFacing` осаждает пыль плавной толщиной: больше на поверхностях, направленных вверх,
  и в локальных углублениях; меньше на вертикальных стенках. Coverage здесь задаёт
  количество отложения, а не порог островков. Шейдер мягко приглушает контраст и блик;
  тонкая грязь окрашивает материал, не перекрывая его рисунок.
- Контрастная светлая/тёмная обводка сколов убрана. Расчёт рёбер и вогнутости отбрасывает
  соседей из других UV-островов; маска имеет двухпиксельный запас у границ развёртки.
- Прогресс очистки учитывает оставшуюся толщину слоя, включая полупрозрачные края.
- Пинцет может последовательно снимать покрытие от открытого края внутрь.

## Свет и материалы

Окружение и реставрируемые предметы используют общий `FirewatchLighting.hlsl`.
`Toon Flattening`: 0 — плавный объём, 1 — плоские toon-зоны. Начальные значения:
0.35 для окружения и 0.25 для предметов. Тени сохраняют различия базовых цветов.

`Bare Material Gloss` даёт чистой основе слабый блик до нанесения лака.
При смене URP Lit на ToonRestorable исходный `_Smoothness` задаёт его начальную силу.
`Coating Relief` задаёт небольшой визуальный рельеф края покрытия через нормаль;
геометрия меша не меняется. `Wear Detail Strength` теперь действительно меняет детализацию.
Для настройки ToonRestorable можно использовать исходный материал с этим же шейдером:
его параметры сохраняются при создании экземпляра материала.

Для cozy-реставрации уместны тёплый свет, цветные мягкие тени и простое окружение.
На предмете полезно оставить блики и различия слоёв: они делают результат работы заметным.
Один шейдер не задаёт весь стиль Firewatch: нужны согласованные палитра, модели, туман,
освещение и постобработка. Эта правка не перенастраивает сцены и глобальную цветокоррекцию.

## Инструменты

`SurfaceTool` передаёт из `ToolProfile` параметры `wetAdd`, `needWet`, `peel`,
которые прежде были доступны только в прямом вызове `RestorableItem.Stroke`.
Для будущего профиля губки: wetAdd = 3, needWet = (0,1,0,0), wearSub = (1,1,0,0).
Для пинцета: peel = true, wearSub = (0,0,1,0).
Существующие профили кисти и ножа сохраняют поведение: новые поля по умолчанию выключены.

## Проверка

Изменённые C# файлы отдельно скомпилированы Roslyn со ссылками на сборки
Unity 6000.0.60f1 и текущего проекта. Это проверка типов и синтаксиса, не запуск игры.
Отдельный запуск Unity не был разрешён: компиляция HLSL, GPU-проверки мазков и
визуальный результат в сцене пока не подтверждены.

В Unity проверьте два экземпляра вазы с wearSeed = 0, затем два с одинаковым ненулевым
seed. Проверьте очистку, работу от края при peel = true, покраску, лак и Console.
Изменение общего света влияет на все материалы FirewatchLit: оцените также интерьер
и улицу. Для масок нужны UV без перекрытий и Read/Write меша; у текущей вазы включены
Read/Write и генерация UV1.
